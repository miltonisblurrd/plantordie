# Tasks

One folder per request. Chief creates it at intake.

Copy nothing forward until the previous file exists.

- `board.md` — original ask, quoted. Who sent it. Opened date.
- `blast.md` — files, remotes, features. Citations only.
- `cut.md` — version, in-scope, out-of-scope, acceptance checks.
- `brand.md` — UI constraints, or the single line `non-UI`.
- `qa.md` — PASS, FAIL, or BLOCKED against the frozen checks. Preview evidence named.
- `proof.md` — VP gate. PR link only after every row is filled.
